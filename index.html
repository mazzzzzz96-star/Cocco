نصب اپ روی گوشی

بدون فروشگاه اپ، مستقیم روی صفحه‌ی اصلی گوشی‌ات. گوشی‌ات را انتخاب کن:

  1. این صفحه را حتماً با Safari باز کن (نه کروم، نه داخل تلگرام یا اینستاگرام).
  2. دکمه‌ی اشتراک‌گذاری را بزن: مربعی با فلش رو به بالا (پایین صفحه یا کنار نوار آدرس).
  3. منو را بالا بکش و Add to Home Screen (افزودن به صفحه‌ی اصلی) را بزن.
  4. بالا سمت چپ یا راست Add را بزن.

آیکون CoccoBye روی صفحه‌ی اصلی ظاهر می‌شود. از این به بعد از همان‌جا باز کن.

اگر دکمه‌ی بالا را نمی‌بینی، دستی نصب کن:

  1. این صفحه را با Chrome باز کن. اگر از تلگرام آمده‌ای، منوی ⋮ را بزن و Open in browser را انتخاب کن.
  2. منوی ⋮ (سه نقطه‌ی بالای صفحه) را بزن.
  3. Install app (نصب برنامه) یا Add to Home screen را بزن.
  4. در پنجره‌ی بعد Install یا Add را بزن.

آیکون CoccoBye به صفحه‌ی اصلی و لیست برنامه‌ها اضافه می‌شود.
